# ATEN Enterprise Development Rules

## Project Overview

Build a world-class Enterprise Progressive Web Application (PWA) for ATEN Industrial Connections.

Primary Website:
https://atenlink.com

Primary Product Reference:
https://atenlink.com/industrial-connections/

## Mission

The application must feel like a native iOS and Android application while remaining an installable Progressive Web App.

The goal is to become the most premium industrial B2B platform in the Middle East.

## Non-Negotiable Rules

- Analyze the entire website before generating any code.
- Preserve the ATEN brand identity.
- Improve the user experience without changing the business identity.
- Do not use templates.
- Build everything from scratch.
- Use enterprise software architecture.
- Write production-ready code only.
- No placeholder code.
- No payment gateway.
- Replace checkout with a professional RFQ (Request for Quotation) workflow.
- Every product must support QR Code.
- The app must work perfectly on iPhone, Android, Tablet and Desktop.
- The application must be installable as a PWA.
- Follow Apple Human Interface Guidelines.
- Follow WCAG 2.2 AA accessibility standards.
- Follow OWASP Top 10 security guidelines.
- Prioritize performance, scalability, maintainability and clean architecture.

## Tech Stack

- Next.js
- TypeScript
- Laravel
- MySQL
- Redis
- Docker
- REST API
- PWA
- Service Workers
